# 同源传输边界

本目录是待部署审阅材料，未运行 Nginx 或发布站点。默认开发服务器没有业务反代，不会访问 Core。真实部署及 Key、费用联调仍需用户单独明确授权。

浏览器只请求部署登记的 `/core-api` 或 `/core-api/registered/{id}`。`createCoreClient` 必须接收已登记连接列表并逐字段匹配；普通地址输入不能新造代理目标。连接与授权绑定在客户端创建时冻结，切换新连接不改写旧任务。

`nginx-canvas.conf` 使用保留域名 `.invalid` 和证书占位符，不能直接作为可用生产配置。后续 T49 根据实际部署填入固定目标和 HTTPS 证书，分别核对公开 API 与已审阅部署契约；当前没有实际部署核验单。额外连接须配置独立固定目标及同样的精确方法/路径校验，不接收 URL 参数、任意 Host 或自定义目标请求头。

允许路径来自固定 Core `c056dffc41c701fb1b78a84c18c2ec139d3d708b` 的公开用户路由，只覆盖健康、模型、文字、素材上传、视频提交/查询/内容/受控交付与作业查询/延续。延续、交付等入口仍由应用能力和独立授权门控。没有余额、充值、取消、admin 或 internal/bridge 入口。

请求不带 Cookie/Referer，Key 仅短时 Bearer 注入；不进入 URL、导出或诊断。重定向手动检查并一律拒绝，不携 Key 跟随其他来源。付费路径要求既有幂等键，已冻结 JSON 字符串直接按原字节发送；传输失败不重试，不生成替代幂等键。代理关闭上游自动重试。

本机测试只使用假 Key 与登记的精确回环 Mock 端口。Nginx 未安装验证和实际 TLS/代理连通性不计通过；保留为部署门槛。
