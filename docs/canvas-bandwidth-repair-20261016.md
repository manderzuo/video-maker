# 画布保存与素材缓存修复（2026-10-16）

生产项目在修订 447 已提交新增文字节点，但浏览器仍显示保存未完成。原始请求的传输错误没有保留，不能认定首次错误的具体异常类型。实际测得保存响应约 272KB，任务列表约 570KB，画布两处轮询分别每 4 秒及 1.5 秒读取完整列表；API 和 Nginx 同时禁用缓存，公网脚本未启用压缩。这些传输会在低带宽下争抢连接并超过旧版 15 秒请求时限。

## 修改

- 客户端声明 `X-Workspace-Transfer: delta-v1` 时，保存只返回权威图差量；旧客户端仍接收完整图。幂等键、事务、修订校验及撤销历史保持原边界；重试同一个请求不会新增重复节点。
- 保存时限为 120 秒，快照读取为 60 秒。超时保留输入和原请求，禁止因超时自动生成新身份重提。
- 画布定期读取所属项目的视频状态摘要，不携带提示词和完整提交正文；两处读取合并在途请求，详情按需获取。
- 所属账号的素材原件、缩略图、素材元数据及画布快照支持私有 ETag 复验。生成视频、截取帧和普通上传素材共用素材读取端点。鉴权、归属、删除状态和文件存在性检查先于 304；错误仍使用 no-store。
- 视频支持原有 Range 读取及 If-Range 校验；不宣称未下载部分已缓存。画布外的视频延迟挂载，有缩略图时先显示缩略图。
- Nginx 启用 JSON、JavaScript、CSS 压缩，移除强制覆盖 API 缓存策略的响应头；其余 API 的默认 no-store 由应用保留。

## 验证与上线边界

已执行 21 项单元检查、71 项服务端检查及 PC/手机专项界面回归。大图保存、连接失败重试、提交成功但响应丢失、撤销重做、视频预览及权限隔离均有覆盖。浏览器测试的生成接口使用隔离模拟，不产生收费调用。

真实生产图仅在回滚事务中测量：完整响应 272084 字节，差量 746 字节；重建图与完整权威图一致，重复请求返回 replayed，真实修订仍为 447。

部署须保留现有手机入口和旧哈希静态文件，先备份数据库及配置并确认全局没有在途付费执行，只重启 Studio。上线后用独立临时账号验证真实 HTTPS、限速保存、图片/视频跨刷新缓存及退出登录权限；验证完删除该账号和它的测试素材。不得提交生产视频、恢复生产自动化或覆盖生产画布。

缓存由同一浏览器管理；首次读取、尚未下载的分段、主动清缓存或浏览器回收缓存后仍需下载。页面缓存不替代云端原件保存。
