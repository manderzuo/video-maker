## 规则

- 新确认任务最多自动重试一次，即原尝试加一次重试；旧失败任务不自动重跑。
- 仅对上游最终确认的 `reference_resource_download_failed` 触发。未知结果、断线、一般超时和安全检查失败不重新生成。
- 重试复用实际优化结果、规格和完整参考上下文，重新上传原素材；不再调用文字辅助模型。
- 原任务与子任务分别保留预算、费用回执和查询。重试可能额外产生视频费用，确认界面已有说明。
- 后台租约、事务和唯一索引保证只创建一个子任务；Core 对同一个原请求使用唯一、永久可追溯的重试身份。并发或重启不会增加第三次尝试。
- 提交回复丢失时，只读找回已创建的子任务编号并继续查询，不重发视频。
