# T48 真实联调：待额外授权，未验收

截至本轮没有真实Core、上游或收费调用授权，没有读取真实Key、历史配置、Cookie或生产数据。真实请求/文字提交/视频提交均为0，请求ID/任务ID为空；费用证据未提供，不能写免费或真实额度硬限已生效。

授权守卫已准备：独立allow-live开关、明确人类授权引用、Studio与原Core服务地址、脱敏原Key绑定、场景、最多1文字+1视频、费用上限和截止时间；缺失、过期、含凭据或Core准入硬限证据未核验时拒绝。JSON Schema在tests/live/approval.schema.json。材料字段校验不验证授权人的身份，也不证明Core已执行限额；当前没有实际额度验证，不作硬限声明。

本地守卫6项用例使用纯内存假授权样本，证明不因开关、缺文档、过期或凭据字段放行；原身份不自动重试、异常后不准备新收费、读取/下载不增加生成计数。它们不是真实联调用例。条件入口npm run test:live缺授权时记录0通过/1跳过、实际调用0；跳过不算通过。即使未来材料校验成功，入口也只报告待真实执行，不自动请求接口或读Key；实际probe执行器尚未在真实授权范围内完成，不伪称已实现或已测。

授权后由用户或安排者给出准确测试部署、已核验文字/视频模型及规格、一次文字和一次视频的最终输入、准入预算证据与到期时间。Core普通Key应由用户在专用空白测试标签页中输入，留在该标签页内存，不写审批文件、环境配置、项目、导出、日志或Agent。确认文字优化和视频生成分别留真实请求ID、任务ID和已确认冻结body/幂等身份的脱敏证据；未知提交立即停止新收费，保留原查询与账务状态，下载失败只重试下载。其余离线本地工作继续推进。
