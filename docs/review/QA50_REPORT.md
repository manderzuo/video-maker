## 功能与问题闭环

画布显示可编辑的“生成草稿 → 固定视频 → 尾帧 → 续写草稿”和“原视频 → 修改草稿”。生成结果、尾帧来源、修改来源用带名称的虚线表达；普通文字和媒体执行输入用实线表达。删除来源线即解除画布关联，可撤销、重做和用来源端口明确重新连接。原请求和历史归属不被修改。

旧尾帧通过明确的“补齐来源连线”操作迁移。必须重新核对本地缓存字节和实际视频提取的尾帧哈希，且唯一匹配；缺失、损坏或多来源匹配不猜填，也不恢复主动删掉的新来源线。真实旧项目已执行补齐、撤销、重做和刷新恢复。

整体自审检查了领域校验、命令事务、输入预检、队列、提交和未知结果恢复、授权身份、凭据脱敏、文字优化、Agent 提案、媒体交付、导入导出、写者及运行租约、Companion 来源限制。不是逐行审阅全部历史代码，也不是独立安全审计。
