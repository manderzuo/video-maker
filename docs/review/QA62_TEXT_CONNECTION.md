## 实际发现与修复

用户截图来自 https://studio.gemstory.cn/settings/connections。文字服务为 OpenCode Go，deepseek-v4.1-flash。使用已有授权点击测试后，模型目录返回 HTTP 200，短暂恢复绿色；后续自动检查仍返回 HTTP 200，却再次显示“检测失败／未取得可核验结果”。

根因：loadRegisteredConnections 缓存了添加文字连接之前的登记清单。手动测试会登记服务并记录目录成功，而自动检查还拿旧清单校验，从而抛出 connection_unregistered。修复为成功登记并验证返回档案后使缓存失效，下次读取实际登记清单。不跳过授权、契约或目标匹配检查。

刷新验收另复现视频授权恢复问题：设置页自动选中默认连接调用 choose，误执行 forgetRememberedConnection('video')。当登记清单读取比页面初始化慢时，会先删除凭据，再尝试恢复。修复为恢复默认选择时保留持久授权；用户主动切换、清除连接继续采用原行为。
