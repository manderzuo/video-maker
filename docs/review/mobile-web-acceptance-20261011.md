## 2026-10-12 手机画布补丁

用户已明确要求显示项目内容，单指拖动画布、双指放大缩小。复现发现：手机复用了桌面最低25%的适应缩放，节点跨度较大时全部落在手机视口外；旧缓存视角也可能完全偏离节点。画布尚未取得实际尺寸时进行首次适应，还会算出错误视角。原实现的Chromium原生触控在普通缩放下能工作，但无法操作修复后所需的低于25%的手机视角。
