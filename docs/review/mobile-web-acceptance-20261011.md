## 预览发布方案

仅给 `/m` 与 `/m/` 深链接挂载新前端索引。现有桌面索引、已有静态文件、`cloud-current` 指向和账号后端均保持当前版本；只添加新的内容寻址静态资源，不覆盖已有资源。Nginx 配置先备份，通过 `nginx -t` 才重载，失败自动恢复旧配置。正式移动发布继续等待真机验收，不切换现有正式服务版本。

预览脚本已固化为 `scripts/deploy-mobile-preview.sh`（原审查副本保留于工作目录），发布前需核验同一提交的包、全部资源哈希、未初始化账号/内容、后端依赖和迁移字节一致。切换后检查全部前端资产的 HTTPS 哈希。发布前线上 `/projects` HTML SHA-256 为 `01aa786f61033f493cbde4ba04002b1618b6147255cf07612f7c64709895fa11`。

首次挂载的即时检查读到旧桌面索引，脚本自动恢复了 Nginx 配置，桌面目录和后端仍为基线。受控重载探针确认第1次请求为旧索引，第2–4次请求均为预览索引，原因是 Nginx 重载命令在新工作进程接受请求前返回。发布脚本改为最多5次、每次间隔1秒的就绪检查，持续不匹配仍自动回滚。探针结束后恢复原配置，原始证据在 `probe-preview-reload.log`；最终预览发布和线上浏览器验证待执行。
