所有模型上游为隔离夹具，使用真实临时 PostgreSQL 和本地文件；没有真实收费调用，没有使用正式项目试写。账号和安全 Cookie 在这里是模拟，不能计为手机真机账号验收。

原始日志、截图和构建记录在 `work/mobile-adaptation/`。当前 WebKit 的独立 MP4 数据URL解码也返回 `MediaError.code=4`，即使 `canPlayType()` 返回 probably，因此保留实际解码限制。Blob 上传夹具只在 WebKit 把原始字节捕获后传给真实隔离后端，未修改实际 fetch；上游已记录拦截 Blob 正文缺失的问题：[Playwright #6479](https://github.com/microsoft/playwright/issues/6479)。浏览器媒体能力受系统影响：[官方说明](https://playwright.dev/docs/browsers)。

## 预览发布方案

仅给 `/m` 与 `/m/` 深链接挂载新前端索引。现有桌面索引、已有静态文件、`cloud-current` 指向和账号后端均保持当前版本；只添加新的内容寻址静态资源，不覆盖已有资源。Nginx 配置先备份，通过 `nginx -t` 才重载，失败自动恢复旧配置。正式移动发布继续等待真机验收，不切换现有正式服务版本。

预览脚本位于 `work/mobile-adaptation/deploy-preview.sh`，发布前需核验同一提交的包、全部资源哈希、未初始化账号/内容、后端依赖和迁移字节一致。部署及线上验证尚未执行。
