# 2026-10-12 AI语义识别方案与验收

用户要求从根本上解决提示词变体被误判的问题，并明确时间、上下文等语义应由AI识别，不继续扩展本地正则模板。最新完整修正输入在旧界面复现预检查422，旧校验把 `1.2 / 1.8 / 2 / 9.6 / 15` 当作相反的总时长要求。

## 方案

AI优化请求前只校验明确的结构化规格及锁定选择、非空输入、大小、方向、账号配置、草稿修订和素材权限。正文不参与本地规格提取，不根据正文推断未选择的参数。配置的文字模型在既有同一次优化请求中阅读完整原文，区分视频长度、动作持续时间、绝对或相对时间点、分镜区间、对白中的数字及历史规格；修正任务结合当前提示词和本次要求，续写区分历史片段与新增内容。

已选择规格和明确采用值优先；模型应保留未要求变更的时间轴与台词，对真实冲突及不确定内容在既有warnings字段写明原文依据和需确认事项，不移动时间、删台词或新增情节以隐藏问题。不额外增加识别调用，不自动生成视频。本地“规则整理”仍为离线功能，使用原规则；AI请求及AI结果检查不再调用该正文启发式。

AI结果仍受JSON结构、明确锁定内容、参考别名、分镜数字合计和已确认规格约束；这些检查不代替语义识别。AI报告warnings时，结果标记为needs_review，并通过既有结果检查界面显示原始提示。保留配置的模型、用户的付费确认、任务持久化、输入修订快照和不自动重试付费请求的流程。
