# 账号云端版本：空内容发布准备

用户明确：发布不附带过去的资料；当前没有账号或内容。以本地代码为准，既有推送、部署授权继续有效。本阶段不创建或导入生产用户、项目、素材、任务、历史、API 配置。

本阶段增加画布停止输入后的自动保存、手动旧资料迁移工具及生产后端入口。旧资料仅在用户点击读取后进入只读清单，另行确认归属后才能导入；新版首次进入不会读取或导入旧 IndexedDB。生产发布不依赖旧资料迁移。迁移暂存文件计入普通上传与视频结果的用户配额。

后端启动使用外置配置、版本化加密根密钥、私有文件目录及 PostgreSQL；数据库迁移使用事务、校验和与执行记录，不创建初始账号或业务内容。生产反向代理保留真实 HTTPS Origin、Cookie 和 Set-Cookie，旧匿名代理入口返回 404。客户端地址仅信任本机反向代理写入的地址。

发布构建使用全新空目录和空环境文件目录。归档清单明确列出程序、当前构建静态资源、锁定依赖、7 个建表迁移、服务配置和依赖许可证；排除本地工作目录、旧发布产物、用户数据、测试资料和秘密。公开视频能力仅沿用固定源码审阅，收费确认仍保留，本阶段没有真实付费生成。
