# QA54：Alt＋鼠标滚轮缩放

画布支持 Alt＋滚轮向上放大、向下缩小，范围为 25%–200%，以鼠标所在位置为中心。Ctrl／Command＋滚轮保留；工具栏缩放按钮和百分比输入仍以画布中心缩放。缩放百分比悬停提示包含新快捷键。

原处理只识别 Ctrl／Command，Alt 滚轮会平移画布。同时滚动文本节点会冒泡到画布，导致内容和画布一起移动。现使用可取消的原生滚轮监听：缩放手势避免浏览器或节点同时滚动；普通滚轮在节点内交给节点内容处理，画布空白处继续平移；弹窗开启时不处理画布滚轮。监听随页面卸载清理。
