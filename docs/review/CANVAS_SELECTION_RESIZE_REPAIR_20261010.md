# 画布点击显示与鼠标尺寸调整修复

基线：`98d408422297b611029e1495670c8376b49e34f9`。

用户报告点击节点后显示错误、原有节点大小拖动操作消失。本轮沿用原节点组件、账号隔离与云端保存，不改业务接口、数据迁移或生成流程。

## 已复现的根因

旧 `CanvasPage` 加载 `node-resize.css` 并传递 `--canvas-scale`。账号画布 `CloudCanvasSurface` 复用了 `NodeResizeHandles`，却遗漏这两项接入。选中节点时，无样式按钮占用正常布局，将正文下挤 48px；角手柄只有 16px，距底边 307px，画布缩至 50% 时点击目标进一步缩为 8px。

修复将必需 CSS 导入放到 `NodeResizeHandles` 自身，并由账号画布传递实际缩放比例。沿用原有右边、底边与右下角手柄、尺寸限制、预览与一次保存机制。

- 修复后定向 3/3：选中前后正文位置偏差不超过 2px；右下角手柄在边缘且点击区域 28px；鼠标拖动将 320×380 调整为 400×430，数据库只增加一次命令，撤销、重做和刷新保留尺寸及正文；50% 画布下 40×25 屏幕拖动正确映射为 80×50 世界尺寸。
