# 账号云端项目、提示词与文字任务开发检查点

在本地 `feat/account-api-cloud` 的 `bc206a5` 基础上继续。任务 4、5 仍在实施，此提交不是完整可部署版本。

本阶段实现：项目复制、包含原件/缩略图/画布/撤销历史/提示词全版本的 ZIP 导出与显式导入，导入事务、ID 重映射和重试回执；连续文字输入合并为有限画布操作；素材元数据、搜索和私有缩略图读取，修复重复原件补充缩略图时的信息丢失。

提示词库和视频写作草稿已按账号保存，保留输入与结果的每个修订，支持回收站、恢复、规则整理、人工结果、历史结果恢复及应用到新的或现有文字节点。结果来源指向原输入快照，保存冲突保留本页输入。

文字 AI 优化由服务端先保存预览和确认后的任务，再执行固定 HTTPS 接口。任务冻结账号、地址、模型、配置修订和密钥版本；不同账号不共用密钥，目录外文字模型可调用。重复确认返回同一任务，网络结果未知和过期发送租约不会自动重发。收到的安全结果先持久化，再写入草稿，数据库保存失败可继续保存而不重复调用。服务端 worker 为显式启用项；任务中心及刷新恢复已接入。导出的任务作为只读历史导入，不能恢复执行或授权。

实际验证（固定 Node 22.23.3 / npm 11.6.2）：后端完整 217/217、前端完整单元 665/665；账号/API/项目/提示词/文字任务联合界面 22/22。类型检查、改动范围 ESLint、构建通过。联合测试发现并修复“已完成任务配合较旧草稿读取时不显示结果”的时序缺陷，专门用旧草稿响应和已完成任务构造失败后复验。已查看结果历史和任务详情截图。最后将输入快照展示改为中文字段；该展示修改另做类型、Lint 和构建检查。
