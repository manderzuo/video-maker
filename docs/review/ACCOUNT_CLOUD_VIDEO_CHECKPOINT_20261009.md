## 本阶段实现

- 云端视频预览冻结用户项目修订、明确连线输入、原件清单、已核验规格、API 配置及密钥版本；用户确认费用后才持久化并执行。预览不调用上游。
- 复用原有视频请求、预检和任务观察逻辑；服务器只使用任务保存的原授权。配置轮换不会改绑旧任务，重复确认返回同一任务。
- 参考素材上传与生成提交先记录状态；无法确认请求结果时记录未知，绝不自动重复上传或生成。执行租约过期同样保守恢复。
- 原任务查询可以暂停、恢复；尚未开始的任务可以撤回。无原任务编号时不能通过查询按钮中断提交或再次发出生成。

- 画布增加规格选择、生成预览与确认、任务详情、原查询控制和结果插入；结果与原任务的关联由服务器验证。
- 项目复制及完整项目包包含视频原件、只读任务历史与来源关系。导入重建 ID 和结果文件记录，不携带执行授权，不加入执行队列，保留原记录的归属。
