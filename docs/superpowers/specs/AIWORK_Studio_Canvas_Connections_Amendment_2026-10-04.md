# 画布连线交互增补 · 2026-10-04

用户确认范围：支持像 ComfyUI 一样按需添加已有类型节点，用可视连线建立输入关联，删除连线解除关联。用户已确认本次短设计并要求实施；沿用原设计 6.2、N-13、N-15 的领域与执行边界。

- 输入端口在视频草稿左侧；文字、图片和固定结果的输出在右侧。颜色与文字共同区分文本、图片、视频。
- 从输出拖向输入显示实时预览；兼容输入高亮；类型不匹配、自连、重复连接等由既有领域校验拒绝。
- 点击输出再点击输入，以及键盘 Enter／空格，是拖动的等价操作。空白落点、Escape、失焦或指针取消撤销尚未建立的连接。
- 连线可选中，Delete／Backspace 删除关联；右键菜单提供断开与关闭。文字编辑中的删除键不删除画布连线。
- 删除经统一 `remove_edge` 命令写入，更新视频草稿的 `inputBindings` 与待更新状态；节点和历史 Run 不删除、不改写。撤销／重做与刷新恢复沿用现有事务和历史机制。
- 一段文字可供多个视频草稿使用；更换输入通过先断开再连接完成。只读画布和锁定的目标节点不能修改关联。
- 仅支持原产品定义的节点和类型。没有新增任意脚本节点、ComfyUI 执行后端或新的模型引擎；生成仍经现有服务、参数检查和收费确认。
