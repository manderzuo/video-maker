# 视频来源连线与修改入口实施记录

用户要求尾帧续写在画布直接关联原视频，结果页增加修改入口。实施范围为现有续写、领域输入解析、结果操作与本地备份；本轮没有开启上游原片修改能力，也不调用真实生成接口。

原视频素材/固定结果节点新增可选tailFrame记录：提取图片assetId、sourceAssetId、sourceRunId、timeSeconds。图片保存为本地素材，执行连线仍使用现有image端口；来源节点就是原视频，端口与连线显示“尾帧”。校验原视频、任务和图片类型；来源变化或文件缺失阻断执行，不自动发送完整视频。普通video连线的语义不变。

续写创建优先复用同一视频的未锁定节点；否则添加固定原视频引用。文字单独连接。删线、撤销、重做、保存与快照沿用原命令引擎。输入预检、提示词素材读取和引用索引读取派生图片。选择其他结果版本时清除旧尾帧记录，防止将原尾帧误标为新结果来源。旧草稿没有来源证据，不自动迁移。

结果页“修改并重新生成”读取所选Run.inputSnapshot，保留原规格、参考ID、顺序和别名，建立独立文字节点和视频草稿。revisionSource记录原projectId/runId/assetId。打开/取消不保存作品；确认保存本地草稿，进入画布后单独确认新视频调用。原Run、素材、body、幂等键和账务不覆写。失败事务回滚，归档项目禁用。此功能不是原片局部修补或Core作业改版。

项目包导入补齐sourceAssetId的身份重映射，防止恢复后尾帧来源指向旧素材。新字段可选，原数据不覆盖；旧客户端遇到新增字段应更新后打开，不使用旧页面写回新草稿。
