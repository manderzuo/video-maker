# 视频素材失败一次自动重试

范围由用户“设置为最多重试一次”确认。规则只处理已经确认的上游素材下载失败，原任务账务继续独立核对；新尝试可能新增视频费用。

1. Core 核验原用户/Key、原预算的最终失败结果，创建固定幂等身份的子请求。
2. 子请求复用实际提示词与完整执行快照，重新上传素材，不调用辅助模型。
3. Core 保存永久重试来源，拒绝子请求的再次重试；重复和并发调用共享同一个子请求。
4. Studio 在保存失败结果的事务内创建唯一子任务；保留原任务状态、编号和账务。
5. 提交回复丢失时，通过只读接口找回子任务身份，再查询原子任务；不重发生成请求。
6. 新确认任务冻结上限一次；旧任务不追溯。确认界面显示可能额外收费，任务详情显示重试关系。
7. 部署契约显式声明 `videoRetry:true` 才开启策略。先部署 Core，后迁移 Studio 011 并更新后台和两种前端产物。

验收：隔离回归验证重复请求、并发与重启、失败上限、原账务不改、提示词复用、未知状态不重发、跨 Key 隔离；前后端类型检查、单元回归、构建和上线只读核验。

生产部署保留数据库和配置备份，不自动恢复旧数据库，不重跑历史付费任务。AI Work 本次不需修改或重启。
